# Evaluation Artifacts

This directory stores small, reviewable evidence files:

~~~text
environment.remote.json
evaluation.json
evaluation.csv
benchmark.csv
summary.md
SHA256SUMS
~~~

Large videos, datasets, and checkpoints must be hosted outside the Git repository.

The final evaluation.json must validate against evaluation.schema.json. Tables in the
technical report must be generated from the immutable JSON/CSV results.
